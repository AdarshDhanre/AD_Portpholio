## 💻 Local Setup & Preview

To run this portfolio locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/AdarshDhanre/AD_Portpholio.git
   ```

2. **Navigate to the project folder:**
   ```bash
   cd AD_Portpholio
   ```

3. **Open in browser:**
   - Double-click [`index.html`](index.html) to open directly in any browser.
   - Or use VS Code's **Live Server** extension for real-time preview.
