SMS Spam Detection System

Problem: High volume of unsolicited spam messages degrades productivity and poses security risks to users.
Solution: Developed a machine learning classifier trained on 5,000+ labeled messages. Utilizes NLP text preprocessing, tokenization, stop-word elimination, and TF-IDF feature extraction.
Tools: Python, Scikit-learn, NLP, TF-IDF, Pandas, Streamlit, SQL.
Result: High-precision classifier distinguishing legitimate text messages from malicious spam in real time.

Tools: Python, TensorFlow, Keras, OpenCV, Pandas.

Student Fee Defaulter & Management System

Problem: Manual tracking of overdue college tuition fees creates heavy administrative overhead and payment reconciliation delays.
Solution: Engineered a modern full-stack web application with role-based authentication (Admin & Student portals). Features offline challan parsing via Google Gemini 2.5 Flash OCR, Razorpay payment gateway integration, and automated n8n + Brevo email notification workflows.
Tools: Next.js 14, TypeScript, Python, Flask, Supabase (PostgreSQL), Gemini 2.5 Flash OCR, Razorpay API, n8n.
Result: Completely eliminated manual receipt verification and accelerated fee recovery with real-time audit trails.
